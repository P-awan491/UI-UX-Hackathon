# UI-UX-Hackathon

Modern nonprofit fundraising website template for Lumora Global, built with Next.js App Router and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to view the site.

## Included

- Home, Programs, Program Detail, Donate, and Impact/About pages
- Responsive mobile-first UI
- Reusable component architecture
- Centralized mock NGO content
- Donation amount selector and summary flow
- Program filtering, progress bars, loading skeletons, and theme toggle
